# 产品经理应用结构表

> 复制为 `inputs/<application-id>-结构.md`。先填写业务结构；不知道的内容写“待确认”，不要填入虚构业务数据。稳定 `application-id` 只使用小写字母、数字和连字符。

## 使用说明

每个业务应用都由平台提供固定壳层：顶部用户栏、应用一级导航、Module + Tab 应用二级导航。产品经理只需定义应用身份、Module、Tab 和页面业务内容；单页面也保留一个选中 Tab。Max 平台左栏属于平台级能力，不是应用一级导航。

产品档位与设备模式分开填写：Basic / Pro / Max 是能力档位；本表以 `1920 x 1080` 桌面端为基线，移动端、紧凑密度和大屏密度均为 `deferred`。

应用生成后，Codex 会同时生成 `outputs/<application-id>/本地预览.html`。该文件可直接双击打开（无需安装 Node.js），渲染的就是将要发布到演示环境的那一份应用源码（所见即所推），用于确认结构与视觉。
